# ReadLog — application mobile

App Expo (React Native) de ReadLog. Installation, lancement et architecture : voir le [README principal](../README.md).

```bash
npm install
EXPO_PUBLIC_API_URL=http://<IP-de-ton-PC>:8000/api npx expo start
npm run typecheck && npm run lint
```

Build et publication (APK Android, version web) : [DOCS/DEPLOY.md](../DOCS/DEPLOY.md).
